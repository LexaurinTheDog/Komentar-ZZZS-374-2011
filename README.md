# Komentář k zákonu č. 374/2011 Sb., o zdravotnické záchranné službě

Otevřený komentář k zákonu o zdravotnické záchranné službě — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; poskytování zdravotnické záchranné služby, zdravotnické operační středisko a výjezdové základny, výjezdové skupiny, oprávnění a povinnosti, traumatologický plán, působnost ministerstva a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2011-00374_2024-01-01`.
